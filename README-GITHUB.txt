FAIRY FINDER ✨
1. Upload semua isi ZIP ke repository GitHub.
2. Pastikan index.html berada di folder utama repository.
3. Untuk lagu: masukkan MP3 sendiri ke folder music/ lalu beri nama fairy-music.mp3.
4. Aktifkan GitHub Pages: Settings → Pages → Deploy from branch → pilih main → / (root).
5. Buka link GitHub Pages kamu.
